# Tenisu API

- Use NestJS and TypeScript. Keep HTTP validation and persistence separate from tennis calculations.
- Keep the implementation small. Test API contracts, statistics, persistence, and failure cases.
- Keep API keys and AWS credentials outside Git.
- Use standard NestJS features before introducing custom abstractions.
- Verify changes with the smallest relevant tests, then run `npm run check` before publication.
- For NestJS implementation and refactoring, read [.agents/skills/tenisu-nestjs/SKILL.md](.agents/skills/tenisu-nestjs/SKILL.md).
- For a requested security review or security-sensitive change, read [.agents/skills/tenisu-security-review/SKILL.md](.agents/skills/tenisu-security-review/SKILL.md).
